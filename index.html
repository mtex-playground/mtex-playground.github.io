    What MTEX gives you

    Read data from any source

    Whatever the instrument, the data lands in one data model and runs through the same algorithms, so maps from different microscopes compare directly.

    • EBSD and ACOM from every major vendor
    • 3D data from Xnovo, DREAM.3D and Neper
    • X-ray and neutron pole figures
    • Export to vendor formats

    Beyond the acquisition software

    MTEX goes on where acquisition software stops: it covers analyses the vendors leave out and brings diffraction and EBSD data together in one place.

    • ODFs from X-ray and neutron pole figures
    • Parent grains for any orientation relationship
    • Tensor properties from texture
    • Variational denoising of orientation maps

    Open, down to the algorithm

    No black box: every function is source code you can open, and every parameter is yours to set. The core algorithms are published in peer-reviewed papers.

    • Source code on GitHub
    • The papers behind the algorithms
    • AI-assisted analysis you can check
    • Make your improvements part of MTEX

    I have an Oxford map A.ctf and an EDAX map B.ang of the same single-phase steel. Compare the grain size distributions.

    compareGrainSize.m 
    % two vendors, one grain definition
ebsdA = EBSD.load('A.ctf');
ebsdB = EBSD.load('B.ang');
grainsA = calcGrains(ebsdA,'angle',10*degree);
grainsB = calcGrains(ebsdB,'angle',10*degree);

% shared bins, normalized for different map sizes
rA = grainsA('indexed').equivalentRadius;
rB = grainsB('indexed').equivalentRadius;
edges = linspace(0,max([rA(:);rB(:)]),21);
histogram(rA,edges,'Normalization','pdf',...
  'DisplayStyle','stairs')
hold on
histogram(rB,edges,'Normalization','pdf',...
  'DisplayStyle','stairs')
hold off
xlabel('Equivalent radius (map length units)')
ylabel('Probability density')
legend('Oxford','EDAX')

    Import your own data

    The import wizard reads your file, shows the map, and writes the script that loads it.

    Type this in the MATLAB command window:

    import_wizard
    1. Double-click your file in the tree on the left. The wizard reads it and draws the map.
    2. Check the phase table: mineral names, symmetries and lattice parameters.
    3. Check the two coordinate systems against your specimen.
    4. Click Generate import script. The script loads the file without the wizard and becomes the first step of your analysis.

    EBSD, pole figure and ODF files of all common vendors. MATLAB R2022b or newer.

    Type this in the interactive window of VS Code or in any Python session:

    from mtex import *
ebsd = importWizard()

    or, from a terminal, mtex-wizard.

    1. Click your file in the browser on the left. The wizard reads it and draws the map.
    2. Check the phase table: mineral names, symmetries and lattice parameters.
    3. Check the two coordinate systems, map and Euler, against your specimen.
    4. Click write script. The script loads the file without the wizard and becomes the first step of your analysis.

    EBSD files of all common vendors. Installed with pip install "mtex[all]".
