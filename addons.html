    Add-ons and scripts

    Toolboxes that other groups have built on MTEX, and scripts that users share. They are maintained by their authors; questions about them go to the authors.

    TrueEBSD

    Corrects spatial distortions and aligns images with electron backscatter diffraction maps.

    Vivian Tong · GitHub

    ORTools

    Orientation relationship discovery and analysis, with publication-ready figures of microstructures after a partial or full phase transformation. An add-on to the phase transition functions of MTEX.

    Azdiar A. Gazder, Frank Niessen · GitHub

    SSLIP

    Slip System based Identification of Local Plasticity. Identifies slip system activity point by point, by matching digital image correlation displacement gradients to the slip systems derived from EBSD data.

    Tijmen Vermeij · GitHub

    Stabix

    Slip transfer analysis at grain boundaries.

    David Mercier · Read the Docs

    MTEX2Gmsh

    Generates meshes from EBSD data for finite element analysis at the grain scale.

    Dorian Depriester · GitHub

    phaseSegmenter

    Separates crystallographically identical or similar phases by their composition, using reindexed EBSD data and EDS element maps.

    Azdiar A. Gazder, Frank Niessen · GitHub

    CVA

    Orientation dispersion analysis by principal geodesic analysis, including the crystallographic vorticity axis analysis of Michels et al. (2015), which tracks the vorticity axes of shear zones.

    Zachary Michels · GitHub

    crystalAligner

    Computes the stage tilt and rotation that align one or two crystal directions or plane normals with the coordinate system of a scanning electron microscope.

    Frank Niessen · GitHub

    Share a script

    Scripts shared by users are public GitHub gists tagged #mtexScript. To share one of yours:

    1. Sign in at gist.github.com and upload the file.
    2. End the description with #mtexScript.
    3. Click Create public gist.
